# Audit d'octobre 2026 — avant / après la refonte

Audit Impeccable (5 dimensions, 0 à 4). Avant : build 224 (analyse de l'app en ligne le 8 octobre 2026, corrigée après lecture du dépôt). Après : build 237. Les mesures viennent des scripts du dépôt ; ce qui n'a pas pu être testé sur un vrai iPhone est indiqué.

| **Total** | **11/20** (acceptable) | **15/20** (bon) | |

Aucune dimension n'est à 4 : il faudrait pour cela un test sur appareil (VoiceOver, gestes, barre d'état) et la suppression de la dette ci-dessous.

## Ce qui a changé
- Chat coach supprimé (~15 Ko de JS) ; barre à 4 onglets, étiquetée.
- Données en `data/*.json`, service worker versionné, hors-ligne, bandeau « Nouvelle version prête ».
- Vérification automatique GitHub (job `verify`) et contrat d'enrichissement (`docs/ENRICHISSEMENT.md`).
- Compteur de sorties unique (58 = 58), jauge VO₂max sans passage par 0, données vides sans NaN.
- Accessibilité : titres, repères, clavier, texte ≥ 12 px (13 px pour le texte courant), contrastes AA, cibles 44 px.
- Mode sombre complet (l'ancien mode « nuit » était cassé et sans bouton).
- Finition : plus d'easing à rebond (décélération exponentielle).

## Dette connue (non traitée)
- `src/test.js` (test Node) échouait déjà avant la refonte.
- `scripts/preflight.py` et `scripts/release.py` existent en double dans `src/` (l'ancien `release.py` les référence) ; l'ancien `--push` de `release.py` est obsolète.
- 247 couleurs hex en dur dans le CSS (blanc sur accent, fonds sombres fixes, dégradés, SVG) et 7 dans les styles en ligne ; 169 anciennes règles `body.nuit` dont certaines sont probablement mortes.
- Éléments cliquables non natifs rendus accessibles par amélioration progressive (`MutationObserver`) plutôt que réécrits en `<button>`.
- Vérifications visuelles pixel par pixel faites en local seulement (polices différentes sous Linux).
