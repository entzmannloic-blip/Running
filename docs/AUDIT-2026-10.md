# Audit d'octobre 2026 — avant / après la refonte

Audit Impeccable (5 dimensions, 0 à 4). Avant : build 224 (analyse de l'app en ligne le 8 octobre 2026, corrigée après lecture du dépôt). Après : build 238. Les mesures viennent des scripts du dépôt ; ce qui n'a pas pu être testé sur un vrai iPhone est indiqué.

## Score

| Dimension | Avant | Après | Preuve |
|---|---|---|---|
| Accessibilité | 2 | 3 | `scripts/audit_a11y.py` : 385 violations → 0 sur les 4 vues, les feuilles de semaine, les fiches de séance (dont « partielle ») et les composants rares (9 règles). Pas d'axe-core ni de test VoiceOver |
| Performance | 2 | 3 | Premier chargement 389 Ko → 308 Ko compressés (−21 %) ; 3 560 → 655 nœuds DOM au démarrage ; historique des versions (75 Ko) à la demande ; hors-ligne vérifié |
| Responsive | 3 | 3 | 43 cibles < 44 px corrigées ; testé à 390 px (émulation), geste tactile non testé sur appareil |
| Theming | 2 | 3 | Couleurs hex hors jetons 585 → 254 (CSS 247 + styles en ligne 7)  |
| Intégrité d'implémentation | 3 | 3 | Données séparées de l'interface, vérification GitHub, build reproductible ; dette restante ci-dessous |
| **Total** | **11/20** (acceptable) | **15/20** (bon) | |

Aucune dimension n'est à 4 : il faudrait pour cela un test sur appareil (VoiceOver, gestes, barre d'état) et la suppression de la dette ci-dessous.

## Ce qui a changé
- Chat coach supprimé (~15 Ko de JS) ; barre à 4 onglets, étiquetée.
- Données en `data/*.json`, service worker versionné, hors-ligne, bandeau « Nouvelle version prête ».
- Vérification automatique GitHub (job `verify`) et contrat d'enrichissement (`docs/ENRICHISSEMENT.md`).
- Compteur de sorties unique (58 = 58), jauge VO₂max sans passage par 0, données vides sans NaN.
- Accessibilité : titres, repères, clavier, texte ≥ 12 px (13 px pour le texte courant), contrastes AA, cibles 44 px.
- Mode sombre : construit pendant la refonte puis retiré à la demande de Loïc (il n'apportait rien) ; l'app reste toujours blanche.
- Finition : plus d'easing à rebond (décélération exponentielle).

## Dette connue (non traitée)
- `src/test.js` (test Node) échouait déjà avant la refonte.
- `scripts/preflight.py` et `scripts/release.py` existent en double dans `src/` (l'ancien `release.py` les référence) ; l'ancien `--push` de `release.py` est obsolète.
- 247 couleurs hex en dur dans le CSS (blanc sur accent, fonds sombres fixes, dégradés, SVG) et 7 dans les styles en ligne ; 169 anciennes règles `body.nuit` dont certaines sont probablement mortes.
- Éléments cliquables non natifs rendus accessibles par amélioration progressive (`MutationObserver`) plutôt que réécrits en `<button>`.
- Vérifications visuelles pixel par pixel faites en local seulement (polices différentes sous Linux).

## À valider sur l'iPhone de Loïc
Barre du bas et haut de page (zones de sécurité, barre d'état), hors-ligne en mode avion et en 4G dégradée, bandeau « Nouvelle version prête » après une mise à jour.

## Relecture indépendante (fin de refonte)
Aucun problème bloquant. Quatre points « importants » corrigés dans le build 238 : texte illisible en mode sombre sur quelques éléments (le premier audit ne regardait que le haut des 4 vues, il couvre désormais feuilles, fiches et composants rares), fusion automatique contournable par un renommage de fichier (`pr_scope.py` utilise `--no-renames`), contrôle que le numéro de build augmente dans chaque PR (`check_build_increment.py`, dans le job `verify`), test de fin d'année (semaine ISO 53, 1er et 4 janvier 2027).

Points mineurs laissés pour plus tard : le cache d'exécution du service worker ne reprend pas les mises à jour hors-ligne (clés `?v=`), pré-cache sans `cache:'reload'`, double activation clavier possible sur un élément ayant déjà son propre `onkeydown`, écran de chargement retiré même si `app.js` plante à l'initialisation, dépendances de la CI non épinglées (Playwright, actions).

## Retrait du mode sombre (après la refonte)
Décision de Loïc : le mode sombre n'apportait rien. Retiré entièrement (≈170 règles CSS, démarrage, tests, audit et captures sombres) ; le téléphone en sombre n'a plus aucun effet sur l'app.
